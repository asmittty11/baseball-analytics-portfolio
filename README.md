## Featured Project

### Melbourne Baseball Club — Season Analytics & Advance Scouting

**2026–27 season · VSBL Premier Division 1, Australia · Ongoing**

A live, browser-based analytics and scouting dashboard supporting Melbourne Baseball Club. I compile available player and team statistics, build opponent scouting profiles, and produce coaching-oriented reports as games are completed and data are published.

| Explore | What you'll find |
| :--- | :--- |
| **[Interactive Dashboard ↗](https://asmittty11.github.io/melbourne-baseball-dashboard/)** | Filterable batting and pitching data, team and player trends, league standings and comparisons |
| **[Scouting & Performance Reports](https://asmittty11.github.io/melbourne-baseball-dashboard/)** | Matchup-specific advance scouting PDFs, weekly tendencies, coaching notes and archived analyses |
| **[Source Code & Methodology](https://github.com/asmittty11/melbourne-baseball-dashboard)** | Structured JSON data, reporting scripts, quality checks, manual update workflow and publication history |
| **[Most Recent Weekly Tendencies](https://github.com/asmittty11/melbourne-baseball-dashboard/blob/main/text_reports/Melbourne_Weekly_Season_Tendencies_2026-11-24.md)** | November 24 snapshot of Melbourne's performance, source limits and actionable observations |

**How it works:** GameDay player lines and official standings are checked and compiled into cumulative datasets. The website presents sortable records and linked reports, while GitHub Actions publish updated PDFs. Individual player-stat coverage can differ from official completed games; estimates, missing data and source discrepancies are explicitly identified. The project is updated manually, not through a live league API.
